# Slides: Iceberg V3 Meets the Lakehouse: Row-Level Lineage and Schema Evolution for Streaming Data

Given at Iceberg Day - Community Over Code, Glasgow, on Oct 10, 2026.

- `Iceberg-V3-Meets-the-Lakehouse.html`: standalone copy. Opens offline in any browser, and keeps animations and the demo clips. Use arrow keys to navigate.
- `Iceberg-V3-Meets-the-Lakehouse.pptx`: conference deck, exported Oct 8. Animations and video are flattened.
- `source/`: the editable project, exported from Claude Design. Open `source/DatadogDeck.dc.html` through a local web server, e.g. `cd source && python3 -m http.server`, then visit http://localhost:8000. Re-import this folder into Claude to keep editing.
  - `_ds/` holds the Datadog presentation design system tokens and the DRUIDS fonts.
  - `assets/` holds the backgrounds, logos, demo clips and stills the deck uses; `uploads/` holds the original clip uploads.
- PDF: open the standalone HTML and print to PDF (one page per slide).

The deck is published at https://streaming-expert.com/talks/slides/iceberg-v3-lineage-coc-2026/ as a copy synced from this folder.
